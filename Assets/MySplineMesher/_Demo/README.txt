Spline Mesher demo
------------------
Use the menu items:
  GameObject > Spline Mesher > Demo > Road
  GameObject > Spline Mesher > Demo > Fence

They create a spline container with a Spline Mesher and a procedural source mesh, so you can
immediately move knots, try the Roll / Scale / Vertex Color / Conform tools and change settings.
This folder is editor-only and can be deleted without affecting the package.
